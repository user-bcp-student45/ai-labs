# Hallazgos

## Contrato observado de web

Derivado solo del cliente Angular; no se leyó ni verificó el comportamiento de los servicios. No existe `docs/ENDPOINTS.md`, por lo que no hay contrato acordado disponible.

- Login: envía `POST http://localhost:8080/auth/login` con `username`, `password` y `client: "angular-workshop"`. Si la respuesta contiene `data.token`, guarda token, usuario y preferencias en `localStorage`, y navega a `/dashboard`. Evidencia: [web/src/app/login/login.component.ts:41](web/src/app/login/login.component.ts#L41), [web/src/app/login/login.component.ts:43](web/src/app/login/login.component.ts#L43), [web/src/app/login/login.component.ts:46](web/src/app/login/login.component.ts#L46), [web/src/app/login/login.component.ts:47](web/src/app/login/login.component.ts#L47), [web/src/app/login/login.component.ts:50](web/src/app/login/login.component.ts#L50).
- Dashboard: sin token redirige a `/login`; con token envía `GET http://localhost:8000/api/tasks?owner=<username>` con `Authorization: Bearer <token>`. Filtra tareas `ARCHIVED`, calcula etiquetas y ordena por prioridad. Evidencia: [web/src/app/dashboard/dashboard.component.ts:36](web/src/app/dashboard/dashboard.component.ts#L36), [web/src/app/dashboard/dashboard.component.ts:39](web/src/app/dashboard/dashboard.component.ts#L39), [web/src/app/dashboard/dashboard.component.ts:43](web/src/app/dashboard/dashboard.component.ts#L43), [web/src/app/dashboard/dashboard.component.ts:44](web/src/app/dashboard/dashboard.component.ts#L44), [web/src/app/dashboard/dashboard.component.ts:49](web/src/app/dashboard/dashboard.component.ts#L49), [web/src/app/dashboard/dashboard.component.ts:54](web/src/app/dashboard/dashboard.component.ts#L54).
- Logout: elimina token y usuario de `localStorage` y navega a `/login`; las preferencias no se eliminan. Evidencia: [web/src/app/dashboard/dashboard.component.ts:75](web/src/app/dashboard/dashboard.component.ts#L75), [web/src/app/dashboard/dashboard.component.ts:76](web/src/app/dashboard/dashboard.component.ts#L76), [web/src/app/dashboard/dashboard.component.ts:77](web/src/app/dashboard/dashboard.component.ts#L77).
